プロジェクト概要

何をするプロジェクトか

BLDDB は、3x3 ルービックキューブの「ブラインドフォールド（目隠し）」競技で使うアルゴリズムを網羅的に検索・閲覧できるウェブデータベースです。 3-style のコーナー／エッジ（全バッファ対応）、コーナーツイスト、エッジフリップ、パリティ、LTCT & T2C、BigBLD（Wing / X-center / +-center / Midge）など、 競技者が暗記に使う手順を、レターリングスキームや自分の好みに応じて選べるように整理しています。

README によれば、本体サイト（blddb.net）は HTML5/CSS3 で書かれた安定版（v1）で、このリポジトリは 2024年3月から進行中の 完全リライト版（v2、Next.js + Tailwind CSS）です。v2 は v2.blddb.net で先行公開されており、完成後に本体を置き換える計画です。 1人のメンテナ（Zixing Wang）によって継続的に開発されています。

主要機能

できること

アプリ内のメニュー構成と v2 の「What's New」から抽出した、実際に実装されている機能です。

33-style データベース（全バッファ）

コーナー・エッジそれぞれ全バッファに対応した 3-style アルゴリズム一覧。ケースごとに複数の候補手順から好みのものを選択可能。

🧊コーナーツイスト / エッジフリップ / パリティ

3BLD で必要な捻れ・向き違い・パリティのケースも個別ページで網羅。LTCT & T2C（大キューブ向け手法）にも対応。

📦BigBLD（大キューブ目隠し）

Wing / X-center / +-center（tcenter） / Midge の各パーツ種別ごとにアルゴリズムを提供。

🔗ダイレクトリンク & ワイルドカード検索

例: /corner?position=UFR-UFL-UBL&mode=manmade のように特定ケースへ直接リンク可能。* によるワイルドカード指定で複数ケースを一括表示。

✅Algorithm Checker / Commutator

入力した手順が正しいかを検証する Checker と、コミュテーターを生成するツールを搭載。

📄Algorithm Sheets & Nightmare モード

暗記用シート（記憶に残りやすい構成の edge 3-style シートなど）を出力できるほか、レアケース／ランダムケースを練習する Nightmare モードを用意。

🌓ダークモード & 多言語対応

next-themes によるライト/ダーク切替、i18next による日本語・英語・簡体中文対応、ブラウザ言語の自動検出。

📱レスポンシブ & PWA

スマートフォン・PC・タブレットに対応したレイアウト。serwist によるサービスワーカーでオフライン利用を補助。
